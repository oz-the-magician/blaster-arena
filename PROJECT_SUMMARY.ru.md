# BLASTER ARENA — сводка проекта для продолжения в новом чате

Состояние на версию **v105** (5 октября 2026). Браузерный 3D-шутер на арене: Three.js, модели Kenney, без сборщика (ES-модули). Изометрическая камера (основной вид) и вид сзади (клавиша V). Вся работа велась в чате итерациями: правка → тесты → сборка → публикация.

## Как устроен проект

```
blaster-arena-vXXX/
  dist/                      ← сама игра (открывается через локальный сервер)
    index.html, style.css
    game.js                  ← основной код (~4000 строк): цикл, ввод, камеры, бой, боты, HUD, строительство арен
    weapons.js               ← таблица оружия (18 стволов)
    level.js                 ← статический уровень + initializeGeneratedLevel(plan)
    zone-templates.js        ← шаблоны дворов (зон)
    engine/
      lighting.js            ← пресеты света (noon, sunset, dusk, overcast, night), звёздное небо
      post.js                ← пост-обработка: GTAO, bloom, грейдинг, виньетка, радиальное размытие (рывок/бег)
      flashes.js             ← пул из 4 точечных огней для вспышек
      touch.js               ← сенсорное управление (два стика + кнопки)
      ground.js              ← геометрия земли (вырезы под ущелье/ров, подразбиение для рельефа)
      ground-paint.js        ← текстура земли (дворы, пятна, края; тропы выключены)
      relief.js              ← визуальный рельеф: карта нормалей + волна сетки до 0,25 м
      navigation.js          ← многоуровневая навигация ботов (+ локальный refresh)
      jump-pad.js            ← физика падов, PAD_TIERS
      audio.js               ← пространственный звук, лимиты голосов, музыка
    generator/
      arenas.js              ← реестр типов арен, generateArena(seed, type, biome)
      world.js               ← «Ущелье»
      fortresses.js          ← «Две крепости»
      hill.js                ← «Царь горы»
      amphitheatre.js        ← «Амфитеатр»
      biomes.js              ← биомы (пустыня, луг, руины, ночь), автофакелы
      clusters.js            ← библиотека сборок окружения (27 шт.)
      decorate.js            ← декоратор: расстановка сборок + слой мелочи по правилу заполнения
      topology.js            ← логический граф
    assets/                  ← модели (5 паков Kenney + старые), assets/sfx/ — звуки и музыка
    clusters.html + cluster-preview.js  ← каталог сборок
    weapons.html + weapon-preview.js    ← каталог оружия
  tests/                     ← unit-тесты и полные симуляции игры (harness)
  tools/
    build-artifact.py        ← сборка игры в один HTML-файл (для публикации)
    embed-setup.js           ← распаковка встроенных моделей в браузере
    process-sfx.py           ← обработка звуков и музыки
  source-audio/              ← исходные звуки (sfx/) и музыка (music-drive.mp3, music-funk.mp3)
  ARCHITECTURE.md            ← подробный технический журнал по версиям (англ.)
  START_HERE.ru.md           ← как запустить
```

### Команды

- **Запуск локально:** `python3 -m http.server 8000 --bind 0.0.0.0 --directory dist` (или `Запустить игру (Mac).command`). С телефона: `http://<IP Mac>:8000` в той же Wi-Fi сети (`ipconfig getifaddr en0`).
- **Тесты:** `npm test` (19 тестов, включая полные симуляции арен). `npm run check` — проверка синтаксиса.
- **Сборка в один файл:** `python3 tools/build-artifact.py [out.html]` → `build/blaster-arena.html` (~11,6 МБ из лимита 16 МБ; модели сжаты gzip и распаковываются в браузере через DecompressionStream).
- **Пересборка звуков:** `python3 tools/process-sfx.py` (берёт `source-audio/`).

### Параметры адреса (для тестов)

| Параметр | Что делает |
|---|---|
| `?type=ravine\|fortresses\|hill\|amphitheatre` | тип арены |
| `?biome=desert\|meadow\|ruins\|night` | биом |
| `?seed=<строка>` | воспроизводимая арена |
| `?light=noon\|sunset\|dusk\|overcast\|night` | освещение |
| `?music=drive\|funk` | фоновый трек |
| `?weapon=ОХОТНИК` (любое имя) | стартовое оружие |
| `?at=x,z` | старт в точке (например `?type=hill&at=0,0` — вершина) |
| `?overview` | вид сверху на всю арену |
| `?arena=classic` | старый ручной уровень |

### Отладочные режимы harness

`node tests/generated-runtime.mjs <seed> <type> [biome]` — полная симуляция арены. Переменные окружения:
`BOTFLOW=<сек>` (поток ботов), `WALK=<сек>` (случайная ходьба игрока, застревания), `TIMENAV=1` (замер навигации), `PROBENODES=1`, `PROBEHILL=1`. Тест `testClimb` проходит игроком все лестницы с настоящим вводом.

## Что сделано (по темам)

### Арены (4 типа) и генерация

- **Ущелье** (`world.js`): ров-ущелье с переходами, 8 ориентаций. Пады на дне ставятся только под открытым небом (не под мостами). Мосты и переходы твёрдые снизу: прыжок с пада упирается в них.
- **Две крепости** (`fortresses.js`): две крепости + бастион с мостами. Сплошные стены-пролёты (`wallRuns`): зубцы 2,2 м на крепостях, парапеты 1,1 м на мостах и бастионе, проёмы у лестниц.
- **Царь горы** (`hill.js`): три сплошные террасы (3, 6 и 15 м), центральная башня втрое выше ступени. Двухмаршевая лестница на башню с площадками (промежуточная 10,5 м, верхняя 15 м). Ров глубиной 4 м с кольями: падение убивает (~1,1 с), с бессмертием возвращает на безопасное место. 4 моста через ров. Осадный лагерь из 8 сборок вокруг рва, орудия направлены на замок. Усиленные пружины (`springHigh`) у стен закидывают на первую террасу.
- **Амфитеатр** (`amphitheatre.js`): круглая чаша из блоков на сетке 4 м, ристалище и три яруса (2/4/6 м), радиальные лестницы по осям, парапет по верху, факелы и жаровни, ночь со звёздным небом.
- **Биомы** (`biomes.js`): любая арена в любом из 4 биомов (пустыня, луг, руины, ночь). Родной биом выпадает в 40%, остальные по 20%. Биом меняет цвета, свет, рельеф, набор сборок и мелочи, заменяет деревья (ели → пальмы в пустыне). Ночью факелы ставятся автоматически. Выбор в меню «БИОМ».
- **Сборки** (`clusters.js`, 27 шт.): лагеря, рынок, кузница, руины, оазис, корабль на рифе, глинобитный квартал (с падом на крышу), скальный лабиринт, базар, осадные (требушет, баллисты, осадная башня и таран, пороховой склад со взрывающимися бочками, руины стены) и др. Поддержка этажей (`y`), перекраски (`tints`), падов внутри сборки, взрывчатки. Модели осадных орудий Kenney смотрят по +x, пушки по −z, это учтено поворотами.
- **Декоратор** (`decorate.js`): ставит сборки по местам (края, углы, обочины, поле) с проверками. **Правило заполнения:** на сетке 4 м «мёртвая» земля — дальше `deadDistance` от любого объекта. Не больше `maxDead` таких клеток в каждой четверти карты. Сначала сборки, потом мелочь. Параметры биома или типа: `theme.fill`.
- **Слой земли** (`ground-paint.js`): мощение только настоящих дворов (стены от 20 м), вытоптанные пятна, затемнение краёв, лёгкая фактура. Тропы рисовать пробовали, решили убрать (`TRACK_SHADE = 0`).
- **Рельеф** (`relief.js`): только визуальный, физика плоская. Крупные дюны и кочки картой нормалей (слабо) + волна сетки до 0,25 м вдали от троп и построек.
- **Пады** (`jump-pad.js`): уровни `spring` (~3,6 м), `springHigh` (~5,8 м), `blue` (~13 м), `yellow` (~18 м).

### Оружие (18 стволов, `weapons.js`)

- Классы: винтовки, дробовики, ПП, ракетница ЗАЛП, лазер ШТОРМ, лазерная винтовка, клинок.
- **КОБРА** — двустволка: 2 заряда, каждый через 3,5 м раскрывается в 6 дробин.
- **ПУЛЬС** — лазерная винтовка: мгновенный луч, 110 урона, стоп на стене и первой цели.
- **ОХОТНИК** — плазменный клинок (класс 5): горит, пока держишь огонь, тратит заряд по времени (12%/с), режет всех в дуге (40 урона каждые 0,25 с), подзаряжается сам (5%/с). Скруглённое лезвие на всю высоту дула, без анимации взмаха. Боты клинок не носят.
- **ДУЭЛЯНТ:** перезарядка 3,8 с (под звук 8 патронов), урон дробины 15. Винтовки: перезарядка 1,25 с.
- Отдача и тряска по весу оружия (`shotPunch`).

### Игрок и бой

- **Рывок** (ПКМ / кнопка »): обычный — перезарядка 1,4 с. **Мощный рывок** — убийства дают заряды (до 2): вдвое дальше, без перезарядки, таранит врагов (35 урона, оглушение). HUD: «МОЩНЫЙ РЫВОК ×N».
- **Эффект скорости:** при рывке — голубые призрачные копии, полосы, радиальное размытие, расширение обзора. При беге — лёгкое расширение обзора и чуть заметное размытие, без шлейфа.
- **Подкат** был сделан и убран по решению (не прижился). Ctrl больше нигде не используется (Ctrl+W закрывает вкладку).
- **Эффектная гибель врагов:** вспышка, ударное кольцо, разлёт кубиков-обломков.
- **Боты агрессивнее:** 60% обходят с флангов, штурмовые кружат на своей дистанции, при здоровье игрока < 35% все бросаются в атаку (быстрее и чаще стреляют). Страховка от застревания ботов.
- **Волны:** 10 / 13 / 16 врагов.
- **Физика краёв:** `slideOffEdges` — соскальзывание с края только при настоящем падении, подъём на ступень в приоритете (v105).

### Звук и музыка

- 25 эффектов из присланного пака (`source-audio/sfx/`), нарезаны и обработаны `process-sfx.py`: оружие в sci-fi стиле (тон выше, срез низов и верхов, фейзер, фланжер, эхо), все выровнены по громкости.
- `engine/audio.js`: звук из точки события (слушатель — игрок), затухание с расстоянием, лимиты голосов по группам, приглушение при взрывах, общий компрессор. Очереди ПП зацикливаются, пока зажат огонь. Гул клинка, шаги, пады, перезарядки, щелчок пустого магазина, `hit` при попадании по врагу и по игроку. Ракета: пуск при выстреле + отдельный взрыв в точке попадания.
- **Музыка:** два трека (drive, funk), обработаны под общий стиль, бесшовный цикл с кроссфейдом. Трек выбирается по сиду арены. Клавиша M или кнопка «МУЗЫКА» включает и выключает её (запоминается).

### Производительность и сборка

- Фриз при взрывах устранён: локальное обновление навигации (`navigation.refresh`) вместо полной перестройки (~2 мс вместо ~500 мс). Шейдеры эффектов прогреваются при старте.
- Модели грузятся только для текущей арены (`arenaAssetKeys`). В опубликованном файле все модели сжаты gzip.

### Каталоги

- **Каталог сборок:** карточки с превью, копируемые имена, вращаемый просмотр, человечек для масштаба, легенда падов.
- **Каталог оружия:** модели дулом к зрителю, все характеристики, отдельная карточка клинка.

## Известные моменты и что можно доделать

- **Не проверено вживую:** штурм «Царя горы» (ров, пружины, башня), баланс 16 агрессивных ботов на 3-й волне, громкость музыки и звуков (подбирались по измерениям, не на слух).
- **Ботам** иногда всё ещё помогает страховка (их переставляет на маршрут). Настоящая причина упирания до конца не найдена.
- **Платформы в зелёном ущелье** оранжеватые (текстура блока перебивает подкраску). Можно перекрасить сплошным камнем, как на холме.
- **Ночь** может казаться слишком синей: пресет `night` в `engine/lighting.js`.
- **Вес игры** 11,6 из 16 МБ. Новые треки потребуют сжатия сильнее.

### Идеи, которые обсуждались, но не сделаны

- Арены «Кварталы» и «Острова».
- Ритм плотности (чередование плотных мест и пауз, один крупный ориентир на зону).
- Изгиб ущелья (Г- или S-образная расщелина).
- Сочность, оставшаяся несделанной: стоп-кадр при убийстве, отметка попадания у прицела, цифры урона, сферы здоровья и патронов из врагов, счётчик серии убийств.
- Цели на аренах (удержание вершины в «Царе горы», раунды гладиатора в амфитеатре).
- Рефакторинг `game.js` на модули (ввод, боты, HUD, строительство арены).
