# Blaster Arena

Браузерный 3D-шутер на арене: волны ботов, гигант-босс, карточки улучшений и легендарные перки, разрушаемые стены, событие «Тьма». Работает прямо в браузере — на компьютере и на телефоне.

**Играть:** https://oz-the-magician.github.io/blaster-arena/

![Blaster Arena](dist/assets/ui/art/start.jpg)

## Что внутри

- **5 волн** с группами врагов, элитой и гигантом в финале (у гиганта отстреливаются руки)
- **18 видов оружия** шести классов: винтовки, дробовики, ПП, ракеты, лазеры, клинок
- **Карточки улучшений** между волнами и **5 легендарных**: вампиризм, рикошет, цепная молния, взрывной рывок, второе дыхание
- **Боты** с ролями (фланг/штурм), рывками, сменой оружия; **подрывники**, **снайперы на вышках**
- **Процедурные арены**: Ущелье, Царь горы, Две крепости, Амфитеатр, Снайперы на вышках; несколько биомов и вариантов света
- **Разрушаемые стены**, взрывные бочки, комбо, замедление времени, событие «Тьма» с фонариком
- Два вида камеры (сзади / изометрия), сенсорное управление, редактор карт

## Управление

| | |
|---|---|
| WASD | движение |
| Мышь / ЛКМ | прицел / огонь |
| ПКМ | рывок |
| Shift / Space | бег / прыжок |
| E | поднять оружие или аптечку |
| R | перезарядка |
| V | вид сзади / изометрия |
| M | музыка |
| Esc | пауза |

## Запуск локально

Игра — статический сайт в папке `dist/` (ES-модули, без сборки). Нужен любой HTTP-сервер:

```bash
npx serve dist
# или
python3 -m http.server --directory dist 8080
```

Однофайловая версия (всё встроено в один HTML): `python3 tools/build-artifact.py` → `build/blaster-arena.html`.

## Тесты

## Публикация

Каждый пуш в `main` публикует `dist/` на GitHub Pages через `.github/workflows/pages.yml`.
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
