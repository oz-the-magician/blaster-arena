# BLASTER ARENA — версия 48

Браузерная 3D-стрелялка. В архиве полный исходный код, модели, текстуры, локальные библиотеки, лицензии и проверки.

## Запуск

1. Распакуйте весь архив.
2. Откройте терминал в папке проекта.
3. Выполните: `python3 -m http.server 8000 --directory dist`.
4. Откройте в браузере `http://localhost:8000`.

HTML следует открывать через сервер: двойной щелчок по файлу не загрузит ES-модули и модели.

## Новая арена

По умолчанию игра генерирует «Овраг»: 12 связанных зон, размер 220 × 220, низина −5, земля 0, мосты 8, верхняя точка 14–16. Меняются размеры оврага, положение мостов, обходы, набор дворов и укрытий. Все 18 видов оружия появляются на доступных участках карты.

Кнопка «НОВАЯ АРЕНА» создаёт другую планировку. После завершения боя следующий запуск также создаёт новую карту. Для повторения определённого варианта добавьте `?seed=my-arena` к адресу. Прежняя карта сохранена для сравнения: `?arena=classic`.

В игровом мире подключена пока одна схема — «Овраг». Остальные схемы находятся в логическом редакторе `generator/`.

## Управление

WASD / стрелки — движение; мышь — прицеливание; ЛКМ — огонь; ПКМ — рывок; Shift — бег; Space — прыжок; E — обмен оружия; R — перезарядка; V — смена вида; Esc — пауза. На экране есть переключатель бессмертия.

## Последние изменения

- «Залп»: четыре ракеты с небольшой дугой и случайными плавными отклонениями, взрывы по области.
- «Шторм»: точный дальнобойный лазер, проходящий через врагов и стены.
- Полный набор оружия на каждой арене.
- Закрытые боковые стенки спусков в овраг.
- Минималистичное интро BLASTER ARENA.

## Для разработки

`npm run check` — проверка синтаксиса. `npm test` — проверки логики и реальные модели без графического рендеринга. Дополнительный вариант генерации: `node tests/generated-runtime.mjs my-seed`.

`ARCHITECTURE.md` описывает устройство проекта. Автоматические проверки покрывают 300 вариантов планировки, маршруты, лестницы, безопасное размещение предметов и оружие. Визуальная проверка новой арены в браузере в этой среде недоступна.

## Сборка версии одним файлом

`python3 tools/build-artifact.py` собирает игру в один файл `build/blaster-arena.html` со всеми моделями внутри (сжаты gzip). Его можно открыть двойным щелчком или опубликовать как артефакт. Нужен Node.js (esbuild скачивается автоматически через npx).
